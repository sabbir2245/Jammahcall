Muslim Jama'ah App
1. Core Idea
A simple app that helps Muslims find each other and pray together. A person can start a prayer gathering (a "Jama'ah"), and nearby users can see it and join.
Find Muslims. Form a Jama'ah. Pray Together.

4. How a User Creates a Jama'ah
1.Tap "Create Jama'ah"
2.Choose the prayer (Fajr, Dhuhr, Asr, Maghrib, Isha, or Jumu'ah)
3.Choose a location (current location or pick one)
4.Choose a time (now, in 15/30 minutes, or custom)
5.Tap "Create" — the Jama'ah is now visible to nearby users
5. How a User Joins a Jama'ah
1.See a nearby Jama'ah on the Home screen or Map
2.Tap "Request to Join"
3.The organizer accepts or declines
4.Once accepted, the user is added to the Jama'ah
6. Simple User Flow
Need to pray  →  Open app  →  See nearby Jama'ah  →  Request to join  →  Get accepted  →  Pray together
7. Easy MVP Feature List
For a first, simple version, the app only needs:
•Sign up / log in
•Location access
•Prayer times
•Nearby Jama'ahs list
•Create a Jama'ah
•Join / request to join
